# 园区头盔复核演示网站 · v0.1.0 开发计划

目标：汇报人在浏览器内选图，服务器运行 Co-DETR v1 epoch 2，查看可切换的原图及真实检测框，复核疑难项，在演示库查回违章证据。登记和上牌仅作项目背景介绍。

| 负责人 | 负责范围 | 首个验收点 |
| --- | --- | --- |
| 模型聊天 | model/，推理依赖与配置 | 从指定权重真实推理一张原图，返回原图坐标、骑乘角色、戴盔判断与可追溯的模型版本 |
| 后台聊天 | backend/，持久化、批次、审核与记录 | 上传、逐张进度、每车决策、人工复核、批次评分、重启后查回结果 |
| 前端聊天 | frontend/，介绍、工作台、记录查询 | 投屏可读的界面，选图、启动、切换叠框、审核与按来源查记录 |
| 主聊天 | 共享接口、跨模块联调、部署、README、CHANGELOG、Git 版本 | 真模型端到端走查，重试不重复入账，记录已验证环境与服务器待测项 |

## 实施与验收
1. 核对权重、运行环境、已有输入版式及检测语义。约定统一的原图像素坐标、来源事件、车辆组、模型结论、人工结论与任务状态。多面板照片按原图计一次。
2. 三路并行。支持提前上传和现场上传，可选子集或整批识别；用户自备的 100 张无需随仓库分发。确认未戴盔自动建演示记录，已戴盔排除，证据不足进入人工清单。驾驶人、同车乘客均纳入。独立上传照片可按可区分的车辆分别建记录，指定车辆的事件仅处理指定目标。
3. 用少量现有图片验证真实处理、检测框开关、人工改判、正式记录回溯。图级正确率对照独立人工标签，仅对有标签的样本计分并展示分母，无法判断计错。人工处理不修改模型原始得分。现场批次与项目固定评测分开。
4. 提供服务器启动与部署说明、模型与数据放置指引、标签格式、备份恢复及版本记录。权重、上传图片、数据库排除出 Git。全部通过后再标记 v0.1.0；目标服务器吞吐和用户 100 张的实际结果以现场实测为准。

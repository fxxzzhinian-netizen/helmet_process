# 部署与数据维护

网站进程提供前端页面、HTTP API 和任务队列，模型服务进程只接收图片并返回检测结果。两者均使用 Python 3.11，可在同一台机器运行，也可分开部署。浏览器与网站同源。数据写入网站所在服务器的持久磁盘。

## 文件与运行环境

1. 将本仓库复制到目标机器，使用 Node.js 22.12+ 或本机验收版本 Node.js 24。项目根目录运行 `npm --prefix frontend ci`、`npm --prefix frontend run build`。也可把已构建的 frontend/dist 一同交付，目标机器直接提供静态文件。
2. 将原始模型交付包解压到 `model/runtime/`，或设置 `HELMET_MODEL_DIR` 指向含有 infer.py、weights、configs、vendor 的目录。权重文件为 `weights/v1_epoch_2.pth`。包与权重的来源、哈希和运行约定见 [模型接入](../model/README.md)。
3. 建立 Python 3.11 环境，安装与设备匹配的模型依赖，再在同一环境安装 `python -m pip install -r backend/requirements.txt`。macOS arm64 CPU 使用交付包随附轮子；其离线安装命令见模型说明。
4. Windows NVIDIA 可把已有的 Windows 补充包展开到模型目录，按其中 install_windows.cmd 安装 CUDA 环境，再补装后台依赖。Linux NVIDIA 应安装与本机 Python、PyTorch、CUDA 匹配的带算子 MMCV，并准备适配入口，按模型模块文档配置。不同平台的二进制依赖不能共用。用下方方式启动后，先上传一张已知图片，确认返回检测结果与原图坐标。
5. Linux / macOS 可运行 `HELMET_PYTHON=/绝对路径/bin/python HELMET_HOST=0.0.0.0 HELMET_PORT=8765 ./scripts/start.sh`。独立局域网汇报可让浏览器访问服务器 IP 和端口。若对接反向代理，允许批量上传的请求体并保留足够超时。上传实际业务照片时使用受控网络或配置带认证的访问入口。
6. Windows PowerShell 在项目根目录设置 `$env:HELMET_MODEL_DIR`、`$env:HELMET_DEVICE="cuda:0"`、`$env:HELMET_DATA_DIR` 后，运行 `scripts\start.cmd`。也可用模型环境的 python.exe 先执行 `-m model.server`，再执行 `-m backend --host 0.0.0.0 --port 8765`。GPU 服务器速度与驱动兼容性须在目标机实测。

## 模型与网站分开部署

GPU 机器只需模型环境和 `model/` 目录，执行 `HELMET_DEVICE=cuda:0 HELMET_MODEL_TOKEN=<令牌> python -m model.server --host 0.0.0.0 --port 8766`。网站机器只需安装 `backend/requirements.txt` 并准备 frontend/dist，执行 `HELMET_MODEL_URL=http://<GPU机器>:8766 HELMET_MODEL_TOKEN=<令牌> ./scripts/start.sh`。模型端口仅向网站机器开放。接口见[接口约定](接口约定.md#模型服务)。

## 数据与重启

默认数据目录为仓库内 data/。设置 HELMET_DATA_DIR 可更改到持久卷。希望为另一场汇报准备空库时，停止进程再指向新的空目录。保留旧目录即可回看旧批次。

备份前停止该数据目录对应的服务，复制**整个目录**（包括上传图片和 SQLite 数据库）。恢复时指向完整副本，使用相同程序版本启动。仅复制 SQLite 文件会丢失原图。备份权重和程序版本以便复现推理结果。

### Linux x86_64 / CUDA 12.1 示例

下列示例供与 PyTorch 2.1 / CUDA 12.1 兼容的 NVIDIA 服务器使用。先准备 Python 3.11、原交付包及 NVIDIA 补充包，将后者的 infer_windows.py 与 infer.py 放在同一目录。该 CUDA 入口采用 PyTorch 调用。目标服务器仍需验收；其他架构或新版显卡先核对算子与驱动组合。

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install setuptools==69.5.1 numpy==1.26.4
.venv/bin/python -m pip install torch==2.1.0 torchvision==0.16.0 --index-url https://download.pytorch.org/whl/cu121
.venv/bin/python -m pip install -r deploy/linux-cu121.txt -r backend/requirements.txt
.venv/bin/python -m pip install model/runtime/CoDETR_v1_epoch_2/env/wheels/fairscale-0.4.13-py3-none-any.whl
.venv/bin/python -c "import torch; from mmcv.ops import nms; b=torch.tensor([[0.,0.,4.,4.]],device='cuda'); nms(b,torch.ones(1,device='cuda'),0.5); print(torch.cuda.get_device_name(0))"
npm --prefix frontend ci
npm --prefix frontend run build
HELMET_DEVICE=cuda:0 HELMET_HOST=0.0.0.0 ./scripts/start.sh
```

上传一张照片并得到完成状态后，再运行整批。如果直接复制已解压的工作目录，确保运行目录含 env/wheels 中的 fairscale 离线轮子。CUDA 模式在所需算子不可用时会报错，避免误把 CPU 耗时当作 GPU 性能。

# 界面设计原则

1. 保留已有 UI 的设计思路。已有首图、指标色带、数字与标签排版、配色、图表和组件样式优先沿用，只按已确认需求做局部调整。
2. 整体以简洁为主，不在板块之间追加统计说明句、模块编号、重复标题或操作教学。必要说明放在提示、空状态或错误状态中。
3. 首页负责看概况，工作台负责上传、处理与复核，完整名单由违章记录承接。首页指标和图表能直接查回对应记录。
4. 首页的原“上传批次”“进入识别工作台”按钮区域改为滚动播报栏。趋势旁展示地点饼图，以不同颜色区分地点，悬停、点按、键盘聚焦都有反馈。
5. 演示用途缺失的时间、地点可补充稳定展示数据，页面不追加演示标注；保留原始数据及证据，避免改写数据库。
6. 未确认的其他页面和交互先用文字记录，按用户确认的范围修改代码。
7. 工作台保留顶部流体进度栏和动效，上传按钮与进度条对齐。任务状态直接切换列表，移除重复统计图。选择处理按钮采用无边框样式，只有历史已完成任务显示日期筛选。

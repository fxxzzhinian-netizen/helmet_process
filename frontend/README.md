# 头盔识别与复核前端

前端使用 React、TypeScript 和 Vite。项目总览、识别工作台和违章记录共用同源 `/api`。首页配图为生成的园区骑行场景，业务页面读取后台保存的现场照片、检测框和事件。

## 构建与运行

在 `frontend/` 执行以下命令。已用 Node.js 24 验证。

```sh
npm ci
npm run build
```

后台默认托管 `frontend/dist/`。独立开发可先启动后台，再运行 `npm run dev`。默认代理至 `http://127.0.0.1:8000`，其他地址可通过 `HELMET_API_ORIGIN` 指定。页面、图标和首页配图均随构建提供，浏览器无需访问外部 CDN。

## 演示路径

首页沿用园区首图、居中数字与标签的指标色带。首图按钮区域替换为滚动播报，可暂停、前后切换并查看事件。下方为违章趋势、地点饼图与小时分布，支持近 7/14/30 天及具体起止日期；模型判定与人工确认分开统计。地点采用居中的圆角环形饼图，不显示地点列表；支持悬停、键盘与点按选中地点，数量与占比在底部以无边框单行文字反馈。首页不重复展示说明段落、上传入口和完整名单。

首页图表跳转到记录页时带上日期、地点、来源或小时条件；打开详情、关闭后保留条件，返回总览保留原日期范围。演示资料缺失的抓拍时间与地点在前端按图片标识稳定补齐，原有字段优先保留，不写入数据库。

在 `frontend/` 运行 `npm run test:overview` 检查日期与统计口径，运行 `npm run build` 完成类型检查和构建。

1. 在识别工作台点击“上传批次”，填写名称并多选 JPEG、PNG 或 WebP 原图。可附一份独立人工标签 CSV，表头固定为 `filename,prediction`。传输进度取自浏览器实际上传字节，传输完成后等待服务器校验并保存。
2. 识别工作台（`#/work`）首页展示最近一批的胶囊进度、各状态张数、图级正确率及运行入口，下方是数据分析，不直接展示照片、文件队列和人员资料。可选全部批次或单个批次，切换近 7、14、30 天；八个指标可切换主折线，包含处理图片、确认违章、待人工复核、已关联目标、检出骑乘人次、识别失败率、图像识别率、人员关联率。下方两张多系列折线展示图片处理结果与事件判定分布，可点击图例开关曲线。统计接口 `/api/analytics` 每 4 秒同步，指标与曲线使用同一批次、日期范围。进度条的流体渲染取自 luoban25.github.io 的 Fluid Progress（代码在 `src/vendor/luoban25-fluid-progress/`，由 `src/Capsule.tsx` 调用；该仓库没有附带开源协议文件，对外发布前需取得作者许可或换掉），浏览器不支持 WebGL 时显示静态进度。
3. “历史批次”（`#/batches`）列出全部批次，可按名称和状态筛选。也可从工作台的“批次详情”进入 `#/work?batch=<id>`；详情保留左侧“已处理 / 待处理”文件队列，右侧原图与识别结果，以及下方违章关联台账和导出。主图按可用宽度显示，长图滚动查看，鼠标悬停可局部放大，可切换原图、整车框、骑乘人员框或全部框。默认展示合并判断和逐人状态，同一人员在上下图使用统一标签，冲突显示黄色待确认框；可切换“原始输出”核对原始检测。图层和事件关联筛选对两种来源均有效，坐标保持与原图一致。
4. 从车辆事件进入复核，保存结论与说明。违章记录支持按判定来源、批次和关键词筛选。事件详情提供当前去向、模型依据、人工历史、返回原批次及原图的入口。无法唯一归属的整图事件使用后端 events 的实际范围。

## 联调记录

- 在独立临时数据库中，以 Chrome 操作真实后端与 Co-DETR v1 epoch 2。先选一张运行，再处理余图，两张均完成推理。测试图及测试复核保存在临时目录，发布包只含前端资源。
- 对一张 4096 × 6336 的多面板图比对 14 个真实检测框的图层数量，抽查首框相对原图的坐标。验证指定框、纯原图、4 倍滚动、确认违章、按人工来源查回、重新复核排除、原图追溯，以及复核前后批次得分保持一致。
- 用 16 个传输测试文件进行限速上传，观察到多个中间百分比，上传完成后才跳转至批次。现场自备 100 张的耗时与吞吐仍需在部署服务器实测。
- 已检查首页、工作台、事件详情在 320、375、390、768、820、1024、1440 像素宽度下的横向边界，已查看桌面与手机首页截图、桌面工作台和追溯弹窗截图。
- design-taste-frontend 的营销落地页门禁在首轮报告 37 项未通过，集中于全屏首图、顶栏导航、分屏节奏、CTA、栅格与静态锚点规则。本前端保留业务侧栏、同屏指标和 hash 路由，以上浏览器检查覆盖实际跳转、交互与布局。

接口字段以 [接口约定](../docs/接口约定.md) 和 [后台说明](../backend/README.md) 为准。

工作台优先使用新的统计接口；已有后台尚未重启、该接口返回 404 时，前端通过原有只读接口汇总同口径数据。兼容读取限制并发，缓存已完成图片的统计摘要，在识别进度、人工结论或关联版本变化后更新，当前运行中的服务也可直接展示趋势。
